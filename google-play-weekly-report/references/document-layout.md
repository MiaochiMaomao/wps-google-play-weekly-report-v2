# Document layout rules

Use the previous report as the design authority.

## Preserve

- page size, orientation, margins, headers, and footers;
- section order and title hierarchy;
- font families and color palette;
- table fields that remain applicable;
- reliable closed historical periods.

## Allowed local changes

- resize images while preserving aspect ratio;
- change chart orientation when category labels require it;
- adjust column widths, wrapping, row height, and cell padding;
- reduce local font size modestly;
- insert page breaks and repeat table headers.

## Geometry

- Prefer inline images.
- Never exceed usable page width.
- Never use a fixed row height that clips text.
- Keep long comment columns wider than identifiers and counts.
- Keep images, tables, captions, headers, and footers inside margins.

## Monthly score chart

- Show the exact score beside every existing point using configured precision.
- Match labels to their series and offset close values.
- Leave unavailable future months blank.
- Preserve the template's visual system when it is not organization-confidential.

## Final QA

Check for clipped text, overlaps, overflow, stale periods, unresolved placeholders, broken media relationships, unexpected blank pages, fabricated values, and unredacted personal information. Render every page or require explicit user visual confirmation.
